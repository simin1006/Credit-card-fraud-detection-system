# 💳 Credit Card Fraud Detection Dashboard

## 📌 Project Overview

This project is a Machine Learning based web application developed using **Python** and **Streamlit** to detect fraudulent credit card transactions.

The application allows users to explore the dataset, perform Exploratory Data Analysis (EDA), visualize important insights, and predict whether a transaction is **Fraudulent** or **Normal** using a trained Random Forest Machine Learning model.

---

# 🚀 Features

- 📊 Interactive Dashboard
- 📂 Dataset Overview
- 📈 Exploratory Data Analysis (EDA)
- 📉 Interactive Visualizations
- 🤖 Fraud Prediction using Machine Learning
